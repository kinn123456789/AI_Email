What this module does

When someone fills out the contact form on Coral Academy's website, it doesn't need a separate system — it arrives as a normal email, gets automatically recognized, and has its name, email, phone, and message neatly pulled apart from the raw form text. It then shows up in its own dedicated dashboard, completely separate from the regular inbox, ready for a staff member to reply to directly.

Automatic Recognition

Enquiry emails from the website are recognized the moment they arrive — no manual sorting needed.

Clean Field Extraction

Name, email, phone number, and the actual message are separated out of the form's plain-text layout — the raw template text never shows up in the reply thread.

Its Own Dashboard

A dedicated view, entirely separate from the main inbox, listing every enquiry with search across name, email, phone, and message.

Reply Like Any Email

Replying works exactly like a normal email reply — it goes straight to the visitor's real email address.

Sent History

A filtered view shows only the enquiries that have already been replied to — easy to see what's still outstanding.

Under the hood

Technical details

Detection rule email_filter.py

An email is recognized as a contact-form enquiry when both are true:

  • The sender is no-reply@coralacademy.com
  • The subject starts with "New Contact Form Enquiry" (not case-sensitive)

When matched, it's tagged with category "Contact Form Enquiry" and mailbox "contact_form" — which is what routes it to its own dashboard instead of the main inbox.

Field extraction process_email.py

In simple words: the email that arrives is just one plain block of text. Without any processing, staff would see this whole messy block instead of a clean record:

Name: ... Email: ... Phone: ... Message: ... Submitted at: ...

So the code reads it and pulls out each piece on its own:

  • Name — takes the text after "Name:"
  • Email — takes the text after "Email:"
  • Phone — takes the text after "Phone"
  • Message — the actual question the person typed. Grabs everything after "Message

Where the data lives database.py

  • Contact name and phone are stored in their own dedicated columns on the messages table.
  • The dashboard query specifically excludes Coral Academy's own internal addresses, so only real visitor enquiries ever show up.
